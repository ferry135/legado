  • 功能与入口（对照现状逐项核对）：① 点击进组——整卡即热区，cv_content click → callBack.onItemClick（BooksAdapterGrid.kt:131-138）→ 标题变「书架(组名)」、只显示组内书籍（BookshelfFragment2.kt:210-219），返回键退回根层（BookshelfFragment2.kt:184-191）；② 长按编辑——root onLongClick → GroupEditDialog(item)（BookshelfFragment2.kt:221-230，重命名/设封面/删除，样式属 dialog_book_group_edit.xml 不在本稿范围）；③ 封面 iv_cover——仍由 CoverImageView 承载 2:3 与圆角（CoverImageView.kt:63-103），空封面落 image_cover_default（BookCover.kt:75），transitionName=img_cover 共享元素转场保留（item_bookshelf_grid_group.xml:34）；④ 组名 tv_name——13sp、两行、居中、ellipsize=end 不变，局部刷新链路 groupName/cover payload 不动（BooksAdapterGrid.kt:110-129、BaseBooksAdapter.kt:86-93）；⑤ bv_unread / rl_loading——布局占位与右上锚点（6dp / 2dp）原样保留，GroupViewHolder 现状即未绑定（BooksAdapterGrid.kt:107-140 仅绑定 tvName/ivCover），本稿不新增行为；⑥ vw_foreground 涟漪层不动（item_bookshelf_grid_group.xml:82-90）。
  • XML 配方（控件 id 全部不变）：根 cv_content 加 android:background="@drawable/bg_card_item"（surface_container 底 + 12dp 圆角 + 0.5dp outline_variant 描边；其 state_focused 项即 btn_bg_press，顺带补齐 TV 焦点可见性，书籍格根用的是 bg_item_focused_on_tv）；内层 LinearLayout padding 6/6/6/16 → 10/10/10/12（卡面内距，外距仍由网格 cell 控制）；iv_cover marginTop 10dp → 8dp；新增一枚无 id 的 AppCompatImageView「›」层级指引（与 05 列表稿同做法，item_bookshelf_list_group.xml:77-88）：20×20dp、约束到 iv_cover 右下（bottom/right 各 margin 6dp，对齐徽标 6dp 内缩锚语言）、background 用新 shape bg_chip_nav.xml（oval，solid surface_container_high + 0.5dp stroke outline_variant）、app:srcCompat="@drawable/ic_arrow_right"、app:tint="@color/on_surface_variant"、padding 4dp（64dp viewport 图标视觉 12dp）、importantForAccessibility="no"；tv_name 仅 textColor 改写 @color/on_surface（现 primaryText 为其别名 colors.xml:116，语义对齐 05 稿）。
  • 令牌对照（明 / 暗）：卡面 surface_container #FFFFFF / #1D1B19；卡描边 outline_variant #E4E1D8 / #36342E；芯片面 surface_container_high #EEECE9 / #242220；箭头 on_surface_variant #60656D / #B4B0AA；组名 on_surface #20242B / #F3F0EB。零 primary/accent 硬编码（MASTER.md §4），默认封面为图片资源明暗同图。
  • 与书籍格的区分逻辑：书籍格通栏裸封面无卡面（item_bookshelf_grid.xml:8 仅 TV 焦点底）；分组卡 = 卡面 + 内距 + 「›」芯片，扫视即可辨「文件夹入口」。默认封面态两侧同图，区分度由卡面承担，不另造文件夹图标（项目 drawable/ 无 ic_folder，避免新增图形语言）。
  • 列数自适应：span = bookshelfLayout+2（三~四列，BookshelfFragment2.kt:88-92）；卡面内距、芯片 20dp、组名 13sp 不随列数缩放（对齐 01 稿 04 注记「书名字号不缩小」）。
  • 数据边界：BookGroup 可绑定字段仅 groupName / cover（BookGroup.kt，无成员计数、无未读数），本稿不显示「n 本」计数——需扩展实体与查询，属行为变更另立决策；下拉刷新跟随分组 enableRefresh、排序、溢出菜单、空态等容器行为同 01 稿 05 注记，本稿不涉及。
  • [NEED-DECISION] 取舍：整卡卡面化（本稿默认，对齐 05 列表分组卡语言，区辨度最高、网格密度略降）vs 保持裸封面仅加角标（密度不变、区辨弱）。默认按本稿实施；如需保留裸封面形态，删除卡面与内距两步、仅加「›」芯片即可，id 与行为不受影响。
