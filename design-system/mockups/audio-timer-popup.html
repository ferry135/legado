LEGADO V2 · MOCKUP

听书定时滑条弹窗 · 新界面TimerSliderPopup 重设计

重构 TimerSliderPopup（popup_seek_bar.xml）：听书播放页点左下「定时」键后弹出的分钟数滑条 PopupWindow。现状卡体是 shape_card_view（3dp 小圆角矩形、无描边），与播放页 bg_player_pill（999dp 胶囊）的圆角语言脱节。本稿三处：① 卡体升为 16dp 圆角 + 1dp outline_variant 描边（MASTER §3 弹层级），胶囊语言落在卡内小件；② 数值从次要文字升为主内容（22sp on_surface 居中），补「定时」标签与 0/180 端点刻度；③ 快捷预设芯片为新增可移除项。滑条沿用 ThemeSeekBar（运行时 accentColor，换肤安全），max=180、拖动即设值、显示时回填 timeMinute 等行为全部维持。底稿取 08-system.html s13 听书播放页（恒定暗色，不随日夜切换）；弹窗卡面随主题——浅色=白卡、深色=暖黑卡，即本稿两态唯一差异。

  • 标签与端点 — 顶部「定时」复用现有字符串 @string/set_timer（values-zh/strings.xml:158，iv_timer 的 contentDescription 同源），零新增资源；滑条两端 0 / 180 对应 seekBar.max = 180（TimerSliderPopup.kt:27）。0=不定时（见 §02），180=3 小时。
  • 滑条着色 — ThemeSeekBar 在 init 中 applyTint(context.accentColor)（ThemeSeekBar.kt:12-18 → TintHelper.kt:237-245 同时染 progress 与 thumb），运行时取色、换肤安全，本稿不动；稿面 #FF6B2C 仅为默认主题兜底演示。轨道底色现状为系统默认灰，补 progressBackgroundTint="@color/outline_variant" 统一令牌（非主色，MASTER §4 允许）。

  • 快捷预设（新增·可移除） — 滑条下补一排胶囊芯片 10 / 30 / 60 / 90 / 关闭：点击直接调 AudioPlay.setTimer(值)（TimerSliderPopup.kt:34 同款调用 → AudioPlay.kt:271-280），并同步 seekBar.progress = 值 与值文字回显。不能只走 seekBar.progress = 值：程序化 setProgress 触发的 onProgressChanged fromUser=false，会被 TimerSliderPopup.kt:33 的 if (fromUser) 拦截——芯片只会改「N 分钟」文字而从不设定时。零新服务代码；预设值与通知栏 addTimer 的 +10 步进（AudioPlayService.kt:389-396）同量级。选中芯片 = 运行时 accentColor 实底白字（DECISIONS §8 疗法，GradientDrawable 着色，同 FontAdapter 先例）；未选中 = field 底 + 次要文字。可整体移除回到「仅标签+数值+滑条」（§01）。
  • 芯片选中态同步（新增规则） — 点击与拖动共用同一刷新函数：onProgressChanged（含拖动 fromUser=true 与芯片回显 fromUser=false）内按 seekBar.progress 反刷芯片——命中 10/30/60/90 高亮对应芯片、progress==0 高亮「关闭」；拖到非预设值（如 45）时全部中性、无任何高亮，不近似取整到最近预设（避免「看着选中 30、实际是 45」的误导），此时滑条与值文字是唯一精确指示。稿面浅色屏（30 命中）与深色屏（0 → 「关闭」命中）即该规则的两态。
  • 胶囊语言 — 芯片 999dp 圆角直接对齐播放页 bg_player_pill（tv_timer/tv_speed 顶部胶囊，activity_audio_play.xml:32-66）与 bg_player_cbtn 圆键的圆形语汇；弹窗卡体则取 16dp（MASTER §3 弹层级，与 BaseDialogFragment v2 / dict 弹层一致）——卡体管「弹窗」，卡内小件管「播放器胶囊」，两层语言各归其位。
  • 「关闭」= 0（现状语义） — setTimer(0) 后 timeMinute=0：AUDIO_DS 事件 0 → 顶部 tv_timer 胶囊隐藏（AudioPlayActivity.kt:294-297 visible(it > 0)），递减任务不再触发停止（AudioPlayService.kt:405-421 仅递减至 0 时 stop），即取消定时；值区按 timer_m 显示「0 分钟」。深色屏即初始态：AudioPlayService.timeMinute 默认 0（AudioPlayService.kt:76），show 重载回填 progress（TimerSliderPopup.kt:41-49）后弹窗打开即为 0，顶部无 30m 胶囊。
  • 触控与密度 — 芯片视觉高 32dp、所在行 min-height 48dp 保触控目标（与 dict.html §05「药丸高 32dp、整行 min 48dp」同一处理）；5 枚芯片单行放下无需滚动。滑条本体 min-height 48dp（现状 AppCompatSeekBar 默认拇指热区约 24dp，不足）。
