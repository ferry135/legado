主题列表弹窗重设计（ThemeListDialog）

主题设置 →「主题列表」的 90%×90% 弹窗重设计：每行新增 48dp 四色预览块（主色/背景/强调/底栏，取自 ThemeConfig.Config 真实配色），配夜间/白天元信息与「使用中」标记；保留全部现状功能——点行应用主题、分享、确认删除、剪贴板导入。样本数据取 assets/defaultData/themeConfig.json 四个出厂主题 + 两个用户保存样例（暖橙体系）。弹窗底色 = 运行时背景色（BaseDialogFragment setSheetBackground），预览块描边随预览明度派生、与弹窗 surface 令牌成对，亮暗两套下 A屏黑/纯白主题均可辨。对比度数值为本会话 Python 实算（02 节）。

01 主形态（浅 / 深） 02 预览块解构 · 夜间预览态与 surface 令牌成对 03 状态与反馈（删除确认 / 导入失败） 04 现状功能逐项核对与落地说明
01

主形态（浅 / 深）

浅色手机：当前应用主题为「晨读暖纸」（样张值 主色/强调 #FF6B2C、背景 #FAF9F7、底栏 #FFFEFC），对应行高亮 + 使用中标记。深色手机：当前为「夜航暖黑」，弹窗底色切夜间背景色 #141312，四个夜间主题预览块恒显各自配置配色。全部可点控件 ≥48dp。

  • 容器 — ThemeListDialog.kt:28-31 setLayout(0.9f,0.9f)（稿面 372×800 ≈ 90%×90%）；弹窗唯一底色 = 运行时背景色（BaseDialogFragment.kt:84 view.setSheetBackground(ThemeStore.backgroundColor())，DECISIONS §4 的 16dp 圆角），浅 #FAF9F7 / 深 #141312，随换肤；遮罩 = scrim_dialog 50%（暗 55%）。
  • 顶栏 — 标题「主题列表」（ThemeListDialog.kt:34，values-zh/strings.xml:799）17sp/650 on_surface + 1px divider 分隔；右缘「剪贴板导入」主色文字钮（menu/theme_list.xml menu_import 原样保留，ThemeListDialog.kt:57-67）。亮色主色文字取 #B34A15（对 #FAF9F7 = 5.11:1 ✓，12-missed-2 同源），暗色 #FF6B2C（对 #141312 = 6.53:1 ✓）。
  • 主题行 — min-height 72dp、左右 padding 16dp、元素间距 12dp；结构 = 52dp 四色预览块（圆角 8dp=corner_radius_sm）+ 名称/元信息（flex，min-width:0 省略）+ 分享/删除两个 48×48dp 图标钮；行间 1px divider（对应 VerticalDivider，ThemeListDialog.kt:42）。整行可点 → applyConfig（:106-108），行为不变。
  • 预览块四色映射 — 顶栏带 = primaryColor、正文面 = backgroundColor、底栏带 = bottomBackground、强调条 + 底栏圆点 = accentColor（ThemeConfig.Config，ThemeConfig.kt:319-326）；正文条为装饰纹理，按 ColorUtils.isColorLight(backgroundColor) 派生：亮底 36% ink / 暗底 40% white（装饰性 2.14~3.81:1，识别不依赖，见 02 节）。
  • 名称与元信息 — tv_name 14sp/650 on_surface 单行省略（id 保留）；元信息 11.5sp on_surface_variant：白天/夜间（isNightTheme，ThemeConfig.kt:321，夜间带 11dp 月牙）+ 主色 hex（等宽字体），给「同名多主题」提供可核对的辨识信息。
  • 使用中标记（新增，见 04 [NEED-DECISION]） — ThemeStore 当前四色与 config 四色一致（applyConfig 写入的 cPrimary/cAccent/cBackground/cBBackground，ThemeConfig.kt:173-183）→ 行底 --sel 状态色 + 名称后「使用中」pill（primary-soft 底 + primary-text 字，4.83/5.10:1 ✓）；无一致则不显示，不新增存储。
  • 条目动作 — iv_share/iv_delete id 与行为全保留：分享 share(json,"主题分享")（:81-84,109-111）→ 系统分享面板；删除经 alert「删除 / 是否确认删除？」确认后 delConfig（:71-79）→ 03 节形态。图标钮 36→48dp（item_theme_config.xml:22-24/32-42 现状 <48dp，MASTER §4 修复），图标 20dp on_surface_variant，按下 10% ink/white 状态层；修正 iv_share 的 contentDescription/tooltip 误标「编辑」→「分享」（item_theme_config.xml:25-27）。
  • 不设底部按钮区 — dialog_recycler_view.xml:65-110 的 tv_cancel/tv_ok/tv_footer_left 在本弹窗全部 visibility=gone（应用主题为点行即生效 + RECREATE，无确认步）；RotateLoading/tv_msg 同样未被 ThemeListDialog 使用，稿面不虚构。
  • 列表数据 — adapter.setItems(ThemeConfig.configList)（:53）不变；列表恒非空（DefaultData.themeConfigs 兜底，DefaultData.kt:73-79），不虚构空态。

03

状态与反馈（删除确认 / 导入失败）

弹窗内仅两处二态反馈：删除需 alert 确认（ThemeListDialog.kt:71-79），剪贴板导入失败 toast（:58-66）；其余动作（应用 / 分享 / 导入成功）无中间态。文案逐字取自现有资源，不新增行为。

  • 应用主题 — 点行即 ThemeConfig.applyConfig → 写四色偏好 + isNightTheme → applyDayNight → RECREATE（ThemeConfig.kt:167-189）；弹窗随之关闭重建，无中间确认。
  • 分享 — GSON 序列化单个 Config → share(json, "主题分享") 系统分享面板（ThemeListDialog.kt:81-84）；JSON 四色 + 名称 + isNightTheme，与 02 节预览块一一对应。
  • 导入 — 「剪贴板导入」读取剪贴板文本 → ThemeConfig.addConfig 校验四色可解析（ThemeConfig.kt:142-152）；同名主题覆盖（:128-140），成功刷新列表、失败 toast（03 节）。
  • 删除 — 按 index 删除（:71-79）；正在使用的主题也可删除（无互锁，现状如此），删除后「使用中」标记自然消失。
