批量换源 · 选择书源弹窗

SourcePickerDialog（dialog_source_picker.xml）重设计：书架管理选中多本书 → 菜单「批量换源」→ 全屏弹窗选择目标书源，点行即对所选书籍批量换源。本稿补齐 blend 标题栏（含搜索胶囊）与底部按钮条两块样式；列表行复用 item_book_source（已落地，稿面仅呈现名称·分组）。视觉令牌与 screens 系列一致：主色 #FF6B2C、亮色 #FAF9F7/#FFFFFF/#EEECE9、暗色 #141312/#1D1B19/#242220、blend 顶栏无分割无阴影。

全屏主稿

setLayout(1f, MATCH_PARENT) 全屏弹窗：blend 标题栏（标题 + ⋮ 溢出 + × 关闭）+ 搜索胶囊 + 已启用书源列表（item_book_source 行复用，FastScroll 快滚条）+ 底部按钮条（左「换源间隔 · N 秒」/ 右「取消」）。点行即换源并关闭，无勾选无确认。

  • 容器 — SourcePickerDialog setLayout(1f, MATCH_PARENT)（SourcePickerDialog.kt:59）→ 全屏弹窗，稿面为整屏页面而非居中卡。
  • blend 标题栏 — dialog_source_picker.xml:9-19 TitleBar（attachToActivity=false，contentLayout=view_search）：透明背景、无分割线无阴影（blend 定稿，同 06-rss#S5 / 12-missed-2#s29-A，现状的 primaryColor 涂色已删，Kotlin:69-70 注记）；标题「选择书源」18sp/650 on_surface（Kotlin:71）；右上 ⋮（menu/source_picker.xml 唯一项「换源间隔」保留）+ ×关闭（新增：全屏弹窗屏内退出，行为 = dismissAllowingStateLoss，与底部「取消」等价；44dp 圆形点击区，ic_close tint on_surface）。
  • 搜索胶囊 — view_search 现样式不动：40dp 全圆角、bg_tab_capsule = surface_container_high 实底、上下边距 8dp；hint「搜索书源」（Kotlin:76）、isSubmitButtonEnabled=true（:75，键盘 actionSearch）；onQueryTextChange 实时过滤 flowSearchEnabled（:82-85,94）。
  • 列表 — FastScrollRecyclerView（xml:26-31）快滚条保留（右缘 4dp 主色 45% 胶囊，同 06-rss#S5）；行复用 item_book_source（已落地）：名称 15sp on_surface（cb_book_source 字号，item_book_source.xml:47-48）、行内边距 12/14/12/16（:9-12）、行间 1dp outline_variant 分割线（左缩进 14dp，05-source-rules#01 同款）；分组后缀用 on_surface_variant 次要色（getDisPlayNameGroup 返回「名称 (分组)」单串，BookSourcePart.kt:50-56，建议按 bookSourceGroup 字段分色，整串 on_surface 亦可）；仅已启用书源（flowEnabled，Kotlin:93）。
  • 行点击 — 点行 → callback.sourceOnClick(source) 批量换源并 dismissAllowingStateLoss（Kotlin:143-150）；单选即换，无勾选/确认（起点换源同型）；点行后宿主页 WaitDialog 显示「批量换源 i / n」（BookshelfManageActivity.kt:139-149，不在本稿范围）。
  • 底部按钮条 — dialog_source_picker.xml:53-98 FlexboxLayout（space_between）：左 tv_footer_left「换源间隔 · N 秒」主色文字钮（与 ⋮ 菜单项同行为，见 03 屏；显示当前值作为决策时上下文）；右 tv_cancel「取消」次要文字钮（dismiss）；上缘 1dp outline_variant 分割线，底部留 home indicator 空间；tv_ok 保持 gone（无多选确认语义，样式成对给出见 04 屏）。
02

搜索与空态

搜索胶囊聚焦输入后实时过滤（flowSearchEnabled）；无命中时列表区居中显示 tv_msg 提示（布局占位启用）。标题栏/底部按钮条在两态下不变。

  • 搜索态 — 输入后胶囊内文字 on_surface、右端清除钮（×，tint on_surface_variant）；提交键保留（isSubmitButtonEnabled=true，:75）；过滤走 flowSearchEnabled(searchKey)（:94），仅匹配已启用源。
  • 空态 — tv_msg（dialog_source_picker.xml:42-49，现未绑定）：搜索无结果时显示居中次要文字（secondaryText 14sp，16dp 内边距，gravity=center 现样式）；稿面文案「未找到匹配的书源」，绑定时机 = flow 收集结果为空。
  • RotateLoading — xml:33-40 现未绑定：本地 Room flow 无网络加载态，保持 gone，稿面不出现。

换源间隔

⋮ 菜单项「换源间隔」与底部左钮同一行为：NumberPickerDialog（0 ~ 9999 秒，初值 AppConfig.batchChangeSourceDelay，确定写回偏好）。数值为批量换源逐本之间的等待秒数。

  • 入口×2 — ① 顶栏 ⋮ → menu/source_picker.xml menu_change_source_delay（现状唯一菜单项，保留）；② 底部左钮（常显，带当前值）。两处同调 NumberPickerDialog（Kotlin:110-121）。
  • 弹窗 — NumberPickerDialog：标题「换源间隔」，min 0 / max 9999（:113-114），初值 AppConfig.batchChangeSourceDelay（:116），确定写回偏好（:118）；呈现沿用 12-missed-2#s24 数字选择轮（surface2 选中带 + on_surface 加粗当前值）。
  • 语义 — 批量换源逐本之间的等待秒数（BookshelfManageViewModel.kt:86,112 delay(changeSourceDelay)）；稿面值 5 秒。
04

组件规格与功能核对

本稿两块补样式的组件解剖（blend 标题栏 / 底部按钮条），以及对照现状的功能核对清单。

  • [NEED-DECISION] 勾选框取舍 — 列表复用 item_book_source 后 cb_book_source 既是名称控件又自带勾选框（ThemeCheckBox），而本弹窗是「点行即换」的单选语义，勾选框无功能。稿面按无框体呈现；实现建议 cb_book_source.buttonDrawable = null（一行，仅留文字，字号 15sp 不变）。若希望原样保留框体，行左将出现无功能方框（不推荐，起点换源无勾选）。swt_enabled / iv_edit / iv_menu_more / iv_explore / iv_debug_text 在本弹窗未接线 → visibility=gone。
  • [NEED-DECISION] 取消钮着色 — 现布局 tv_cancel / tv_ok 均为 AccentTextView（运行时 accentColor 主色文字）；v3 弹窗族定稿（12-missed-2 .dfoot）取消 = 次要色。稿面按定稿：取消 on_surface_variant；若不改代码保留 AccentTextView，则取消/确定同为 accent 主色文字（可接受，非阻塞）。
  • 标题栏规格 — 高 56dp（min），背景透明（与弹窗 surface 同色，blend 无分割无阴影）；标题 18sp/650 on_surface 居左；右侧两枚 44dp 圆形图标钮（⋮ 溢出、× 关闭），图标 22dp tint on_surface；其下搜索胶囊 40dp、surface_container_high 实底（bg_tab_capsule）、hint 搜索书源、上下边距 8dp。布局落点：dialog_source_picker.xml TitleBar 不动，新增关闭钮可用 menu 或 navigationIcon 二选一（navigationIcon = ic_close 更省）。
  • 底部按钮条规格 — 上缘 1dp outline_variant（亮 #E4E1D8 / 夜 #36342E）；左右 padding 10dp、上 6dp、下 16dp（避让 home indicator）；文字钮 14sp/600、padding 14dp×13dp（触控高 ≥48dp）、圆角 12dp 按压态 ripple；左槽 tv_footer_left 主色文字（运行时 ThemeStore.accentColor，亮色实色建议 #B34A15 保 ≥4.5:1，同 12-missed-2#s29）、右 tv_cancel 次要色、tv_ok 主色文字（本弹窗 gone）。
  • 功能核对（现状 → 新稿） — ① 入口：书架管理选中态菜单「批量换源」（menu/bookshelf_menage_sel.xml:21 → BookshelfManageActivity.kt:330）不改；② 标题「选择书源」（Kotlin:71）→ blend 标题栏；③ 搜索书源 + 实时过滤（Kotlin:76,82-85）→ 搜索胶囊；④ 换源间隔菜单项（menu/source_picker.xml:5 → Kotlin:112-119）→ ⋮ 保留 + 底部左钮常显（双入口同行为）；⑤ 已启用书源列表 +「名称 (分组)」（Kotlin:93 / BookSourcePart.kt:50-56）→ item_book_source 行；⑥ FastScrollRecyclerView 快滚（xml:26-31）→ 右缘快滚条；⑦ 点行换源并关闭（Kotlin:143-150）→ 行点击（后续 WaitDialog 进度在宿主页，稿外）；⑧ 底部 tv_footer_left/tv_cancel/tv_ok（xml:61-94，现均 gone）→ 左「换源间隔 · N 秒」+ 右「取消」，确定样式成对给出未启用；⑨ tv_msg 空态（xml:42-49，现未绑定）→ 搜索无结果提示；⑩ RotateLoading（xml:33-40，现未绑定）→ 保持 gone。无删项、无新增权限/网络行为。
