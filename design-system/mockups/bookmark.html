书签编辑弹窗 · BookmarkDialog

书签编辑弹窗重设计稿：沿用 12-missed-2 #02 的容器与动作结构，输入区对齐已落地的 dialog_simulated_reading.xml（12-missed-2 #03）——「标签上、值下」的 field 卡排版 + bg_edit_filled 输入实底。功能与入口对照 BookmarkDialog.kt / dialog_bookmark.xml 现状逐项核对，无增删：顶栏标题、章节名只读展示、原文摘录输入、备注输入、删除（仅编辑态）、取消、确定。三屏：编辑态（浅色）、新建态（浅色）、深色说明。

01

编辑态 · 浅色

自书签列表（AllBookmarkActivity 点按条目）或目录抽屉书签页（BookmarkFragment 长按条目）进入，editPos ≥ 0：底栏左端出现「删除」。三个 field 卡同栅格：章节名（只读）、内容（书内原文）、备注内容。

  • 容器 — dialog_bookmark.xml:9-16：FrameLayout(16dp) 内 vw_bg 居中卡（shape_card_view 3dp → BaseDialogFragment 定稿 16dp 圆角，DECISIONS §4）；setLayout(MATCH_PARENT, MATCH_PARENT)（BookmarkDialog.kt:33）→ 全屏遮罩上的居中大卡；adaptationSoftKeyboard=true（BookmarkDialog.kt:20）软键盘顶起卡体。
  • 顶栏 — Toolbar title=书签（dialog_bookmark.xml:18-25）；现状 Kotlin 已无顶栏染色，稿面即随卡 surface 底 + on_surface 标题（17px/650）。
  • 章节名（只读） — tv_chapter_name 展示 bookmark.chapterName（dialog_bookmark.xml:27-33、BookmarkDialog.kt:52）→ 只读 field 卡：与输入域同 16px 栅格、surface2 实底、10dp 圆角，但无 caret、无聚焦描边，值 on_surface 14sp。
  • 原文输入 — edit_book_text（hint=内容，dialog_bookmark.xml:52-57）存取 bookmark.bookText（BookmarkDialog.kt:54、:60）→ field 卡：label 11.5px secondaryText 上、值 14px primaryText 下；bg_edit_filled 实底（surface_container_high + 10dp 圆角），EditText background=@null 多行自增高。
  • 备注输入 — edit_content（hint=备注内容，dialog_bookmark.xml:66-71）存取 bookmark.content（BookmarkDialog.kt:55、:61）→ 同上 field 卡。
  • 删除 — tv_footer_left 仅编辑态 visible(editPos ≥ 0)（BookmarkDialog.kt:49），error 色（:51），点击 bookmarkDao.delete 后 dismiss（:69-76）→ 底栏左端 danger 文字钮（#BA1A1A / 深色 #FFB4AB）。
  • 取消 / 确定 — tv_cancel dismiss（BookmarkDialog.kt:56-58）；tv_ok 回写 bookText/content 并 bookmarkDao.insert 后 dismiss（:59-67）→ 右端 取消（mut）+ 确定（主色文字钮）。
  • 入口 — 书签列表点按条目（AllBookmarkActivity.kt:82，传 position）；目录抽屉书签页长按条目（BookmarkFragment.kt:97，传 pos）→ 均为本屏编辑态。
02

新建态 · 浅色

自阅读页两个入口新建（editPos = -1）：长按选字菜单「书签」（原文 = 选中文本）或阅读菜单「添加书签」（原文 = 当前页全文）。删除按钮隐藏，备注为空时占位提示；稿面演示备注域聚焦态（主色内描边 + 光标）。

  • 入口 ×2（新建） — ① 长按选字菜单「书签」：content_select_action.xml:14 → ReadBookActivity.kt:862，bookText = getSelectedText()（ContentTextView.kt:637-651），选不中正文时 toast「创建书签失败」（strings.xml:848）；② 阅读菜单「添加书签」：book_read.xml:48 → ReadBookActivity.kt:1534-1537，bookText = page.text.trim() 当前页全文。两者 chapterName 均取所在章标题。
  • 删除隐藏 — tv_footer_left visible(editPos ≥ 0)，新建态 editPos = -1（BookmarkDialog.kt:48-49）→ dfoot 仅 取消/确定，删除位留空（sp 占位，不改变其余元素位置）。
  • 占位 — 备注为空时显示 secondaryText 占位文案（对应 EditText hint=备注内容，dialog_bookmark.xml:70；占位文案可沿用 hint 原文，稿面示意扩展写法）。
  • 聚焦态 — bg_edit_filled 实底之上叠 1.5px 主色内描边 + 主色光标（同 12-missed-2 #28 辅助按键录入框先例；落地时 EditText background=@null，焦点描边由 field 卡容器 drawable-selector 承担，textCursorDrawable=shape_text_cursor）。
  • 原文回填 — 新建态内容域直接带入选中文本/整页文本，可再编辑（BookmarkDialog.kt:60 确定时回写）；章节名只读不参与回写。
03

编辑态 · 深色

同一弹窗在夜间主题（跟随系统 Night 资源，非独立皮肤）：暖黑层级化表面，field 卡实底、描边、文字色按令牌镜像，确定钮回主色 #FF6B2C（深底对比达标，无需亮色的深主色替换）。

  • 令牌镜像 — surface #1D1B19 / surface2(field 实底=bg_edit_filled 的 surface_container_high 夜值) #242220 / text #F3F0EB / secondary #B4B0AA / divider rgba(255,255,255,.08) / 删除 #FFB4AB（MASTER.md Dark 表）。
  • 确定钮 — 深色主色文字 #FF6B2C 压 #1D1B19 对比达标，保持主色原值；亮色才替换为 #B34A15（12-missed-2:62 定稿）。
  • 遮罩 — veil 由 rgba(0,0,0,.45) 加深至 .55，弹窗卡保持 1px divider 描边以在暖黑背景上分层。
04

设计调整与落地映射

相对 dialog_bookmark.xml 现状的改动仅排版与皮肤，控件 id 与行为全部保留。

  • 输入区 — TextInputLayout + ThemeEditText ×2（dialog_bookmark.xml:47-73）→ 改 LinearLayout field 卡 + bg_edit_filled 实底（同已落地 dialog_simulated_reading.xml）：label TextView 11.5sp secondaryText 上、EditText 14sp primaryText 下，padding 7/14/8/14dp、卡间距 10dp；edit_book_text / edit_content 控件 id 不变，BookmarkDialog.kt 绑定零改动。
  • 章节名 — tv_chapter_name 裸 TextView（dialog_bookmark.xml:27-33）→ 只读 field 卡（TextView，id 不变），与输入域同栅格；无 caret、无聚焦描边以示只读。
  • 聚焦描边 — bg_edit_filled 复制一份 selector（默认 surface_container_high，focused 叠 1.5dp 主色描边）用于两张 field 卡容器，EditText 自身保持 background=@null。
  • 底栏 — FlexboxLayout 三文字钮结构不变（dialog_bookmark.xml:79-119）：删除(error 色，仅编辑态) / 取消 / 确定(accent)；统一 12dp 触控 padding ≥ 48dp 目标（MASTER.md §1.4）；确定亮色字色用 #B34A15（AccentTextView 亮色定稿同步）。
  • 滚动 — NestedScrollView 保留（dialog_bookmark.xml:35-77）：原文/备注过长时 body 滚动，field 卡随内容自增高。
  • 颜色 — 全部走令牌：surface / surface_container_high / on_surface / on_surface_variant / error / primary（ThemeStore 换肤不固化），不在布局硬编码 primary/accent（MASTER.md §4）。
  • 功能核对（无增删） — 顶栏标题书签 ✓ 章节名只读 ✓ 原文编辑 ✓ 备注编辑 ✓ 删除(编辑态/error 色) ✓ 取消 dismiss ✓ 确定回写+insert ✓ 软键盘适配 ✓ 全屏遮罩居中卡 ✓ 入口 ×4（选字菜单/阅读菜单/书签列表/目录书签页）✓
