LEGADO V2 · MOCKUP

全屏查看与加载弹窗 · 新界面CodeDialog · PhotoDialog · WaitDialog

本组三弹窗现状观感均为直角满幅壳：CodeDialog / PhotoDialog 是 setLayout(1f, MATCH_PARENT) 全屏壳——根 View 虽已由 BaseDialogFragment 运行时挂上 16dp 圆角背景（BaseDialogFragment.kt:83-85），但 dialog window 背景不透明，圆角缺口被填平、遮罩不可见；WaitDialog 是 @color/background 直角居中小壳。本稿一份轻量方案统一三处：全屏两壳 window 设透明（透出既有运行时圆角背景），WaitDialog 新建 16dp 圆角底 + window 透明；文字一律 on_surface 令牌，不固化 primary/accent（MASTER §2/§4）。功能与入口逐项保留——CodeDialog 的查看/编辑双态与保存回调、PhotoDialog 的加载链与双指缩放、WaitDialog 的不可点外关闭与动态文案，见各屏注释与末节落地映射表。

改动落点（文件 · 控件）说明与令牌
① window 透明（CodeDialog） CodeDialog.kt:30-33 onStart（setLayout 处）增 dialog?.window?.setBackgroundDrawableResource(R.color.transparent) 根 View 的 16dp 圆角背景已由 BaseDialogFragment.kt:83-85 挂在同一 View 上（运行时覆盖 XML background，删 dialog_code_view.xml:6 无效）；不透明 window 底是四角缺口被填平的原因，window 透明后缺口透出遮罩（先例 BaseDialogFragment.kt:42-43 adaptationSoftKeyboard 分支）。圆角=corner_radius_lg（ViewExtensions.kt:329-340）。
② window 透明（PhotoDialog） PhotoDialog.kt:36-39 onStart（setLayout 处）增 dialog?.window?.setBackgroundDrawableResource(R.color.transparent) 同①：根 View 圆角背景已存在（BaseDialogFragment.kt:83-85），window 透明后方可见；底色随运行时 ThemeStore.backgroundColor()（暖纸 #FAF9F7 / 暖黑 #141312），规避纯黑大面积背景（MASTER §4）；PhotoView 本体无背景，不动。
③ 等待壳自带圆角 dialog_wait.xml:5 root LinearLayout background → 新建 drawable/bg_dialog_wait.xml（solid @color/surface + 16dp 圆角 + 1dp @color/outline_variant 描边） WaitDialog 不走 BaseDialogFragment，必须自带圆角底；同时在 WaitDialog.init 设 window.setBackgroundDrawableResource(R.color.transparent) 让圆角透出（先例 BaseDialogFragment.kt:42-43，与①②同一手法）。
④ 代码区留白 + 底字令牌 dialog_code_view.xml:18-22 CodeView：android:padding="12dp" → 16dp（spacing_lg）；补 android:textColor="@color/on_surface" 现状 CodeView 未设 textColor（dialog_code_view.xml 无该属性，CodeView.kt / ScrollMultiAutoCompleteTextView.kt 无 setTextColor / primaryText 引用），底字实为主题默认 EditText 文字色而非 on_surface 令牌，需显式声明；高亮 code_*令牌 不改（CodeViewExtensions.kt:24-39）。无行号栏，不新增。
⑤ 工具栏令牌 dialog_code_view.xml:9-16 Toolbar：无属性改动；仅确认背景随容器、标题 ToolbarTitle 20sp（styles.xml:82-84） menu_save 图标色 = 运行时 accentColor（CodeDialog.kt:52 applyTint，已是现状），布局内不出现 primary/accent 硬编码（MASTER §4）。
⑥ 关闭钮（新增·可移除） dialog_photo_view.xml 增 48dp ImageButton（ic_close，右上 12dp，背景 @color/pill_field），onClick dismiss() pill_field 明暗成对：values/colors.xml:92 #0F000000 / values-night/colors.xml:60 #14FFFFFF，提高任意图片上的可见性（MASTER 令牌表无 field 资源，勿自造色值）。全屏窗口无点外区域，现状仅返回键可退；本钮为展示层增强，删去即回现状。返回键/双指缩放行为不动。
⑦ 等待文本令牌 dialog_wait.xml:17-24 tv_msg：textColor @color/primaryText（已别名 on_surface）不动；padding 20dp 不动 无布局改动即达标；如需可加 minWidth 160dp 防止极短文案抖动（可选）。
⑧ 「只读」徽标（新增·可移除） dialog_code_view.xml Toolbar 内增 24dp 高 TextView（仅 disableEdit=true 时 visible，CodeDialog.kt:36-38 处 setVisibility） @color/pill_field 底（values/colors.xml:92 / values-night/colors.xml:60）+ on_surface_variant 11sp；删去即回「仅标题 code view」现状。
[NEED-DECISION] ⑥⑧ 两处「新增」均为可整体移除的展示层增强；①② window 透明是稿面圆角浮层成立的必要改动（无功能影响，先例 BaseDialogFragment.kt:42-43）；③ WaitDialog 圆角底 drawable（bg_dialog_wait.xml）为唯一必须新建的资源文件。
  • 行为保全清单 — CodeDialog：保存回调链 menu_save → onCodeSave(code, requestId) → parentFragment/activity → dismiss（CodeDialog.kt:53-64）与 7 个 Import*Dialog 入口不变；PhotoDialog：4 处入口与三级加载链不变（PhotoDialog.kt:45-68）；WaitDialog：不可点外关闭 + setText 动态文案不变（WaitDialog.kt:13-26）。
  • 换肤 — 三弹窗主色仅存在于运行时 accentColor（保存图标、转圈），容器为中性 surface；ThemeStore 换肤后自动跟随；稿面 #FF6B2C 仅为默认主题兜底演示（MASTER §4、DECISIONS §8）。
