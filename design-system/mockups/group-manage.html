分组管理弹窗重设计

GroupManageDialog（书籍分组管理）· 书架菜单「分组管理」或书架整理页进入的 90%×90% 大窗：顶栏标题 + 添加分组、分组列表（组名 / 编辑 / 书架显示开关）、长按拖拽排序、底部确认。视觉令牌延续 12-missed-2 弹窗稿；列表行严格对齐已令牌的 item_book_group_manage.xml，容器 dialog_recycler_view.xml 为多弹窗共用、本稿不动。

01

分组管理

浅色稿演示长按拖拽态（「新书精选」浮起）；深色稿为常态并演示「添加分组」达 64 个上限时的 toast。内置分组按 getManageName 现状显示身份后缀（如「全部(全部)」），改名后后缀保留身份标识（如「有声书(音频)」）。

  • 入口 — 书架菜单「分组管理」（BaseBookshelfFragment.kt:99 menu_group_manage）与书架整理页（BookshelfManageActivity.kt:292）→ showDialogFragment(GroupManageDialog)；setLayout(0.9f, 0.9f)（GroupManageDialog.kt:51-54）→ 90%×90% 大窗，稿面即 374px 卡 + 遮罩。
  • 容器（不动） — dialog_recycler_view.xml 为 10+ 弹窗共用（AppLog/CrashLogs/6×Import/Icon 等），本稿不改容器：Toolbar + RecyclerView(weight 1) + 分割线 + 底部 FlexboxLayout；rotate_loading/tv_msg 本弹窗不启用；tv_cancel/tv_footer_left 保持 gone，仅 tv_ok 显示（GroupManageDialog.kt:70-74）。
  • 顶栏 — 标题「分组管理」（GroupManageDialog.kt:57，ToolbarTitle 20sp）+ 右侧 menu_add ic_add「添加分组」（menu/book_group_manage.xml，applyTint :91）；点击先查 canAddGroup（BookGroupDao.kt:71-72 计数 < 64）→ 开 GroupEditDialog 新建（GroupManageDialog.kt:96-98），达上限 toast「分组已达上限(64个)」（:100，深色稿演示）。
  • 列表数据 — flowAll 全量分组按 order 排序实时收集（GroupManageDialog.kt:77-85；BookGroupDao.kt:24），含 AppDatabase.kt:167-203 预置的内置组；行名走 getManageName 身份后缀（BookGroup.kt:39-49）：内置组恒显「(全部)(音频)…」身份，用户改名后仍可辨认（稿面「有声书(音频)」）。
  • 列表行（对齐已令牌 item_book_group_manage.xml） — 组名 15sp sans-serif-medium on_surface（xml:14-24）+「编辑」12sp on_surface_variant（xml:26-37）→ GroupEditDialog(group) 编辑态（GroupManageDialog.kt:132-138；改名/封面/排序/允许下拉刷新/删除二次确认，见 12-missed-1 #05；内置组删除隐藏）+ ThemeSwitch（xml:39-44，主色开关，min 48dp）→ upGroup(copy(show)) 控制书架显示（GroupManageDialog.kt:139-145，isPressed 防程序性误触）。
  • 拖拽排序 — ItemTouchHelper isCanDrag，长按触发（ItemTouchCallback.kt:34-37 isLongPressDragEnabled），松手 onClearView 重排 order=1..n 并整批入库（GroupManageDialog.kt:149-163）；稿面拖拽态沿用 12-missed-2 #01：surface2 圆角浮起行 + 阴影 + 主色手势图标，无新增拖拽手柄。
  • 行分隔 — 现状 VerticalDivider 1px（ic_divider = bg_divider_line → outline_variant 别名），稿面为 7%/8% hairline；行底 @color/background（= surface 别名），稿面即弹窗 surface 同底。
  • 底栏 — tv_ok「确认」AccentTextView 运行时 accentColor（GroupManageDialog.kt:70）→ dismissAllowingStateLoss（:72-74）；亮色主色文字压白卡仅 2.84:1，按 12-missed-2 定稿改深主色 #B34A15（稿面 .dact.pri），暗色仍 accentColor；仅一行改动（:70）。
