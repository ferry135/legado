自定义翻页按键弹窗重设计（PageKeyDialog）

PageKeyDialog（dialog_page_key.xml）重设计：为 TV / 遥控器 / 墨水屏设备自定义实体按键的上一页·下一页键值映射——把焦点放到输入框、按物理键即自动录入键值（数字，多个自动以英文逗号分隔）。本稿两件事：① 清除 selector_fillet_btn_bg 的全布局唯一残留使用点（本会话 grep 核实：app/src/main/res 下仅 dialog_page_key.xml 命中，两枚按钮）——输入域换 bg_edit_filled field 卡（对齐已落地 dialog_bookmark.xml 栅格），两枚按钮换弹窗族文字钮底栏（重置=次要 / 确定=主色文字，dialog_bookmark.xml:200-207 同款）；② 输入域由 TextInputLayout（hint 被运行时染成 accent 色）改「标签上、值下」的 field 卡。弹窗为普通 Dialog（非 DialogFragment），setLayout(0.9f, WRAP_CONTENT) 居中呈现，底色=运行时背景色 + 16dp 圆角（DECISIONS §4 口径）。功能逐项保留，见 03 节映射表。

01

主形态（浅 / 深）

宿主为阅读页（TV 首启引导即直接压在阅读页上弹出；更多设置入口的宿主是偏好页，弹窗形态一致，稿面以阅读页为底）。样张键值 24 / 25 = Android KEYCODE_VOLUME_UP / VOLUME_DOWN（音量键翻页是本弹窗最常见用途）；实际值随用户按下的实体键而定。

居中 90% 宽 · wrap 高field 卡「标签上、值下」重置=次要文字钮 · 确定=主色文字钮触控 ≥48dp键值自动逗号分隔BACK / DEL 不录入
  • 容器 — 普通android.app.Dialog，setLayout(0.9f, WRAP_CONTENT)（PageKeyDialog.kt:22-24）→ 稿面 372px 宽居中卡、高度随内容。底色=运行时 backgroundColor（PageKeyDialog.kt:29 contentView.setBackgroundColor(context.backgroundColor) 现状保留语义），落地时圆角化：亮 #FAF9F7 / 深 #141312 + 16dp 圆角（corner_radius_lg，DECISIONS §4 与 BaseDialogFragment v2 同口径），普通 Dialog 需在 kt 侧给 window 或根布局设运行时圆角 GradientDrawable；遮罩=Dialog 默认 dim（稿面 50%/55%）。
  • 标题 — tv_title（dialog_page_key.xml:10-17）「自定义翻页按键」（values-zh/strings.xml:639）18sp/650 on_surface，margin 由 5dp 栅格化为 20/14dp。
  • field 卡 ×2 — TextInputLayout + ThemeEditText（dialog_page_key.xml:19-45，hint 被自定义 TextInputLayout.kt:16-18 运行时染成 accent 色）→ 两张 field 卡：bg_edit_filled 实底（surface_container_high #EEECE9 / #242220 + 10dp 圆角），padding 7/14/9/14、卡间距 10dp，与已落地 dialog_bookmark.xml:41-59 栅格一致；label 11.5sp on_surface_variant（hint 文案 @string/prev_page_key / @string/next_page_key 上移为标签），值 14sp on_surface；et_prev / et_next 控件 id 不变，PageKeyDialog.kt 读写绑定零改动。
  • 帮助文案 — @string/page_key_set_help（values-zh/strings.xml:821）原样保留，12sp on_surface_variant、行高 1.7（dialog_page_key.xml:47-52 现 secondaryText 14sp 默认行距）。
  • 重置钮 — tv_reset（dialog_page_key.xml:60-73）selector_fillet_btn_bg（btn_bg_press 灰底 16dp 圆角）→ 次要文字钮：透明底、on_surface_variant 14sp/600、minHeight 48dp；按压反馈走背景态 android:background="?android:attr/selectableItemBackground"（RippleDrawable，API 21+ = minSdk 21 全覆盖；不用 android:foreground——View foreground 为 API 23+ 能力，minSdk 21 下 API 21-22（老电视盒）静默失效）。
  • 确定钮（方案已选定，评审后定稿） — tv_ok（dialog_page_key.xml:79-92）→ 主色文字钮：透明底、textColor=@color/on_primary_soft（亮 #B34A15 / 夜 design_orange #FF6B2C；dialog_bookmark.xml:200-207 同款同令牌——透明底文字钮，非实底钮）、14sp/650、minHeight 48dp、背景 ripple 同重置钮。对弹窗底 #FAF9F7 = 5.11:1 ✓、对 #141312 = 6.53:1 ✓，明暗双达标。三案取舍：① ReadAloudDialog.kt:180-186 式运行时 accent 填充 + 明暗取黑白——换肤跟随，但默认 accent 明暗同为 #FF6B2C（values/colors.xml:82、values-night/colors.xml:42），白字 2.84:1 不达 MASTER §4；② 静态主色实底——既不随 ThemeStore 换肤又含 ① 的对比问题，弃；③ 本稿文字钮——AA 达标 + 12-missed-2 弹窗族定稿语言。代价如实声明：确定钮文字色为静态资源、不随 ThemeStore 换肤（DECISIONS §8 机制性既限，与已落地弹窗族同口径），运行时 accent 强调保留在聚焦描边与光标；若日后换肤跟随优先，可整钮改 ① 式并接受 DECISIONS §1 取舍。
  • 布局零残留 — 本稿落地后 selector_fillet_btn_bg 在全部 layout 中引用归零（本会话 grep -rn selector_fillet_btn_bg app/src/main/res/ 仅命中 dialog_page_key.xml）；drawable 文件删除或保留由落地者定，其引用的 btn_bg_press 系列色值因 TV 焦点态在 MASTER §2「不动的」清单，不动。
  • 样张数据 — 24 / 25 = KEYCODE_VOLUME_UP / VOLUME_DOWN；实际键值随设备（遥控器方向键 21/22、翻页键 92/93 等），UI 不展示键名映射表（代码无此数据，不虚构）。
02

录入与重置态（浅 / 深）

录入反馈 = field 卡聚焦内描边（1.5dp 主色）+ 主色光标；onKeyDown 捕获实体键追加键值（BACK / DEL 除外，DEL 仍用于编辑文本）。重置仅清空两输入框，需再点「确定」才写回空值解除映射——现状行为，稿面补态演示。

聚焦内描边 1.5dp 主色主色光标 shape_text_cursor按键追加 · 逗号分隔空值占位「未设置」· 新增可移除重置→确定 连用=清空映射
  • 键值录入（行为零改动） — onKeyDown（PageKeyDialog.kt:44-65）：非 BACK / 非 DEL 且 et_prev / et_next 聚焦时，把 keyCode 追加进聚焦框——空串或以「,」结尾直接追加，否则先补「,」再追加，并消费该按键事件（return true，不触发页面翻页）。稿面示例：上一页框原值 24，再按方向左键 → 追加为「24,21」。
  • 聚焦反馈 — field 卡聚焦内描边 1.5dp 主色 + shape_text_cursor 主色光标（12-missed-2 #28 先例，BookmarkDialog.kt:63 setFocusedStrokeColor(requireContext().accentColor) 同法运行时注入，随换肤）；两框均未聚焦时无描边（01 屏）。
  • 重置语义（现状如此） — tv_reset 仅 etPrev.setText("") / etNext.setText("")（PageKeyDialog.kt:32-35），不落盘；点 tv_ok 才把两框当前值写回 prevKeys / nextKeys 偏好并 dismiss（:36-40）。故「重置→确定」连用 = 清空自定义映射、恢复默认翻页；「重置→取消（返回键）」= 放弃清空。稿面深色屏为重置后空值态。
  • 空值占位（新增，可移除） — 现状空输入框无任何提示；稿面补 android:hint="未设置" 占位（on_surface_variant，新字符串一条 values + values-zh）。删掉此行即回到纯现状，不影响任何行为。
  • dismiss 收软键盘 — currentFocus?.hideSoftInput()（PageKeyDialog.kt:67-70）不变；BACK 键不录入、走 super 关闭弹窗（:45 的排除分支）。
