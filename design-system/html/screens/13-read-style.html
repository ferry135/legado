界面设置弹窗重设计（ReadStyleDialog）

阅读菜单「界面」入口的底部弹层：六入口 chip 网格、四组 DetailSeekBar 行（ink 8% 圆角卡+值胶囊）、翻页动画胶囊单选组（选中=主色底白字）、预设色板（圆形色块+预设名+主色 2dp 选中描边）。容器恢复 16dp 顶圆角 + scrim_dialog 50% 遮罩；配色决策收敛到「自适应 ink 状态层」梯度，任意换肤色下成立。护眼预设采用起点读书护眼绿 #C7EDCC（实测对比度见 02 节）。主色 #FF6B2C 可换肤；无外部依赖、明暗双主题。

界面设置弹窗（重设计形态）

浅色手机：正文以护眼预设渲染（#C7EDCC 底 / #465A33 字），弹层底色仍为应用 surface2（#EEECE9）——弹层随应用主题、正文随阅读预设，两者不混用。深色手机：默认夜间正文（#141312 / #ADADAD），色板按 03-#19 的修正恒显白天配色（夜间 5 颗近黑圆不可辨的问题消除）。全部可点控件 ≥48dp。

  • 容器 — 弹层 16dp 顶圆角 + scrim_dialog 50% 遮罩（#80000000，暗色 55% 观感加深）；窗口底透明、弹层唯一底色 = 运行时 bottomBackground，双套背景 token 移除。顶部 4dp grip 条为新增视形锚点（纯装饰，可随 grip 一并落地或省略）。
  • 六入口 chip（2×3 网格） — 字重（中/粗/细）/ 字体 / 缩进 // 简/繁 / 边距 / 信息；14sp、minHeight 48dp、圆角 8dp（corner_radius_sm）、描边 1dp = 25% ink、按下态 12% ink 状态层；id 与点击行为全部保留（tv_text_font→FontSelectDialog、tv_padding→showPaddingConfig、tv_tip→TipConfigDialog）。
  • DetailSeekBar 行 ×4 — 行容器 = ink 8% 圆角 12dp 卡（内边距 14×6dp，行高 56dp，行距 8dp）；± 按钮 48dp（图标 24dp）；滑杆可视高 24dp、热区 48dp、主色滑轨与 18dp 滑块；右侧值胶囊 = ink 10% 底圆角 8dp（padding 12×5），对齐 dialog_auto_read.xml tv_read_speed 的 vchip 形态；稿面滑条比例按真实进度映射（字号 progress = textSize−5，默认 20 → 15/45；字距 60/100、行距 12/20、段距 2/20，ReadStyleDialog.kt:78-85/194-197）。
  • 翻页动画胶囊组 — 5 枚胶囊 min-height 48dp、全圆角；未选 = ink 8% 底 + 自适应 primaryText 字（8% 胶囊叠层上 secondary/62% ink 实算 4.25/4.18:1 < 4.5，不弱化字色；审查第1轮修正，原稿 secondary 字），选中 = 主色底白字 650 字重（需求 3 指定形态；白字对 #FF6B2C 实测 2.84:1，为 v3 全局既有形态——书源胶囊/主按钮同款，见 03 节 #14 说明）。
  • 配色方案行 — 「文字颜色和背景（长按自定义）」12sp secondary；右侧「共用布局」14sp + 主色开关（ThemeSwitch，38×22dp，on=主色轨），行高 48dp、整行可点。
  • 预设色板 — 横向 RecyclerView（现结构不变）：48dp 圆形色块 + 12sp 预设名（名称移出圆外，不再叠印在色块上）；未选描边 1dp（25% ink）、选中描边 2dp 主色 + 名字主色 650；末尾「自定义」ghost 虚线圆 + 加号，列表右侧 44dp 渐隐提示可横向滚动（footer 行为不变：新建 Config() 后转 BgTextConfigDialog）。
  • 自适应 ink 梯度 — 弹层只取一次 textColor = getPrimaryTextColor(isColorLight(bottomBackground))，派生 3 档：分割线 12%、容器 8%、胶囊 10%（均 ColorUtils.adjustAlpha，非文字用途）；次要字不做 alpha 派生，直接用 on_surface_variant 角色令牌（getOnSurfaceVariant(isLight)：亮 #60656D / 暗 #B4B0AA，均 ≥4.5:1）。62% ink 在 #EEECE9 上实算 4.38:1（<4.5，违反 MASTER §1/§4，审查第1轮修正），令牌 #60656D 同面 4.98:1 达标；替换固定 divider_subtle 与 alpha 0.75 弱化（03 节 #16/#22）。

  • #C7EDCC 的理由 — 起点读书护眼模式标志性的柔和黄绿（#C7EDCC 一族），与旧「预设3」的 #C2D8AA 同为浅绿但更明快；亮度足够高（相对亮度 ≈0.77），深色文字可稳定达标；本稿同步把预设名改为「护眼」——盘点确认六个出厂预设（微信读书、预设1~5）中不存在名为「护眼」的预设（grep 全量 0 命中），观感最接近的「预设3」就地更名，不新增预设位。
  • 夜间不变 — 该预设夜间仍为 #3C3F43 / #88C16F（4.99:1 ✓），本稿不改动；#3C3F43 属 MASTER §4 冷灰遗留，与预设2/4/5 共用，留待统一处理。
  • 触控 — 色板单元格（圆+名）整体可点，高 48+6+12=66dp ≥48dp；相邻间隙 8dp 起步（横向 RecyclerView 自然滚动，满足间距规范）。
  • 页眉页脚口径 — 护眼预设未设 tipColor（Config 默认 0），PageView.kt:84-85 回退正文色渲染，稿面页眉页脚同步用 #465A33（5.92:1 ✓）；初稿用的灰 #6D6A62 对 #C7EDCC 实算 4.22:1 不达标，已弃。
