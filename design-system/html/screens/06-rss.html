01 · 订阅主页

fragment_rss.xml · ui/main/rss/RssFragment.kt

主界面「订阅」Tab：blend 顶栏 = 标题「订阅」+ 菜单（收藏 / 分组 / 设置），下方为搜索胶囊（支持 group:分组名 过滤），正文为 4 列订阅源网格（图标 56dp 圆角 14 + 名称两行），首位固定「规则订阅」入口；底部导航当前 Tab 高亮。长按任一源弹出纯文字菜单（与 PopupMenu 实际渲染一致）：置顶 / 编辑 / 禁用源 / 删除。网格末行展示超长源名两行截断；下方补充空态呈现。

  • 顶栏菜单 = main_rss.xml：收藏(star) / 分组(groups，子项为源分组，点击按 group: 搜索) / 设置(进入订阅源管理)
  • 网格首位为固定入口「规则订阅」→ RuleSubActivity（adapter.addHeaderView）
  • 长按菜单 = rss_main_item.xml：置顶 / 编辑 / 禁用源 / 删除；统一纯文字项（RssAdapter:65 用 PopupMenu，菜单图标默认不渲染），危险项 error 色
  • 空态 = 圆底图标 + 主文案「RSS 源目前为空！」(rss_source_empty, 14sp on_surface) + 导入提示 (12sp on_surface_variant)；落地：fragment_rss.xml 把 tv_empty_msg 换成竖排 LinearLayout，图标复用 ic_bottom_rss_feed，提示为新增 string
  • 超长源名两行截断（tv_name lines=2 + ellipsize=end，13sp on_surface_variant），网格复用 12 色瓦片
  • 点击源：单 URL 源直接进阅读页，多分类源进 RSS 分类页

02 · RSS 分类

activity_rss_articles.xml · ui/rss/article/RssSortActivity.kt

进入某个订阅源：blend 顶栏（返回 + 源名称），其下为按 sortUrl 生成的可滚动分类 Tab，正文为下拉刷新的文章流。默认 articleStyle 列表样式 = 左标题两行 + 斜体时间，右侧 110×68 缩略图；底部「加载更多」。图中展示了溢出菜单的全部真实项。

  • 顶栏标题来自源名称（viewModel.titleLiveData）；溢出菜单 = rss_articles.xml：登录(有 loginUrl 才显示) / 刷新分类 / 设置源变量 / 编辑源 / 切换布局 / 阅读记录 / 清除

  • 分类 Tab：仅 1 个分类时隐藏 tabLayout；下拉刷新 SwipeRefreshLayout（主色指示器）
  • articleStyle 支持 3 种：紧凑列表(0) / 大图列表(1) / 网格(2)；「切换布局」可切网格
  • 触底加载 LoadMoreView；「阅读记录」弹出记录对话框（dialog_recycler_view + 清除菜单）
