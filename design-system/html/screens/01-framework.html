书架 · 标签模式

fragment_bookshelf1.xml · fragment_books.xml · item_bookshelf_list.xml · BookshelfFragment1.kt · menu/main_bookshelf.xml
  • 顶栏：大标题「书架」28sp bold（blend 同色顶栏、无分割线），常驻「搜索」图标；「⋮」收拢 11 项操作，合计 12 项菜单 menu/main_bookshelf.xml:6-77，各项行为见 BaseBookshelfFragment.kt:92-121（更新目录 / 添加本地 / 远程书籍 / 添加网址 / 书架管理 / 缓存导出 / 分组管理 / 书架布局 / 导出书单 / 导入书单 / 日志）。
  • 分组胶囊 Tabs：每个分组一个 Tab，48dp 高胶囊、选中主色填充、分组多时可横向滚动；指示器随页面滑动同步 fragment_bookshelf1.xml:26-48、BookshelfFragment1.kt:101-116；长按 Tab 编辑分组（GroupEditDialog）BookshelfFragment1.kt:221-224；重复点击同组 Toast 提示书籍数 BookshelfFragment1.kt:251-257。
  • 排序入口：「按阅读时间 ▾」弹出 6 项排序菜单：按阅读时间 / 按更新时间 / 按书名 / 手动排序 / 综合排序 / 按作者 BookshelfFragment1.kt:49-56、162-176、values-zh/strings.xml:245-248,1144-1145。
  • 列表条目：封面 88×123、书名 20sp bold 单行省略、未读徽标（橙=有新章节高亮，灰=普通未读计数；徽标文字色由 BadgeView 按底色自动取黑/白 BadgeView.kt:128-132）、作者 + 上次更新时间、最近阅读章节（tv_read=durChapterTitle）、阅读进度（tv_last=「阅读至 n% · 时间」，BooksAdapterList.kt:70-86）、行内「⋮」更多（同长按：进书籍详情）、弱分割线 item_bookshelf_list.xml:16-222。v3 修正：第三行是阅读进度而非最新章节（v2 稿误标「最新：」，实际数据见 BooksAdapterList.kt:70-86）；长书名/长章节名在图标后单行省略（左稿第四行）。
  • 更新中状态：目录刷新时徽标位变为旋转加载 BooksAdapterList.kt:89-91；下拉刷新 = 更新当前分组全部目录 BooksFragment.kt:99-102。
  • 快速滚动条可开关（书架布局对话框）BooksFragment.kt:135-138。
  • 空书架（明/暗两稿）：tv_empty_msg 增强为「图标 + 文案」两段式，纯 XML 可达——给 fragment_books.xml:21-32 的 TextView 加 android:drawableTop（书本线稿 vector）+ app:drawableTint=@color/outline + drawablePadding=12dp，textSize 14→15sp、lineSpacingExtra=4dp；不新增 id、不动 Kotlin（BooksFragment.kt:193 只控显隐）。文件夹模式空态同理（fragment_bookshelf2.xml:34-49）。空书架时底栏「等待更新」徽标为空、不显示。
  • 触控区统一：行内「⋮」32→44dp、glyph 20dp 不变，与顶栏 icon-btn 同规格 item_bookshelf_list.xml:29-41；「按xx排序」min-height 44dp fragment_bookshelf1.xml:57-73。MASTER 的 48dp 触控标准如需严格执行，应与 TitleBar 顶栏按钮一并放大（跨组统一决策，本稿未单方面改顶栏）。
  • 溢出菜单表面：菜单底色映射 background_menu→surface_container_high——亮色 #EEECE9、暗色 #242220（生产 colors.xml 实装值，本稿 --surface-high，见暗色菜单展开稿），暗色下不再与页面背景贴面。

书架 · 网格模式（三列）

item_bookshelf_grid.xml · BooksFragment.kt（bookshelfLayout=1）
  • 网格形态：bookshelfLayout=1 时 RecyclerView 换 GridLayoutManager 三列，顶部结构（顶栏 / 胶囊 Tabs / 排序）不变 BooksFragment.kt:103-107；style2 下同理 BookshelfFragment2.kt:88-92。
  • 网格条目：封面通栏 2:3、书名 13sp 居中最多两行（长书名两行截断见左稿第二行右格）item_bookshelf_grid.xml:30-81；点击进书、长按进书籍详情（与列表一致）。
  • 徽标内缩（v3 修正）：未读徽标/加载圈由 v2 稿的「悬出封面角 7dp」改为封面内右上角 6dp 内缩——负 margin 在 Android 不可实现，v2 实施时只能贴角锚定；本稿对齐可实现形态，XML 只需给 bv_unread / rl_loading 加 6dp margin item_bookshelf_grid.xml:43-64（加载圈外圈含 2dp 底衬，锚点取 2dp 使圆心与徽标对齐）。
  • 行距（v3 补记）：条目 LinearLayout 现只有 6dp 上/左/右 padding、无底部 padding，纵向行距仅靠书名两行撑开；加 paddingBottom=16dp 即可对齐本稿 16px 行距 item_bookshelf_grid.xml:15-23。
  • 列数可配置：书架布局对话框可选 列表 / 网格三~六列 dialog_bookshelf_config.xml:86-121；切换布局立即重建 BaseBookshelfFragment.kt:209-219。列数增加时徽标保持右上角、书名字号不缩小（保证可读性）。
  • 伴随开关：显示未读标志 / 显示上次更新时间 / 显示等待更新数量 / 显示快速滚动条 dialog_bookshelf_config.xml:34-68、BaseBookshelfFragment.kt:171-204；未读关闭时徽标整体隐藏 BooksAdapterList.kt:97-99。
  • 下拉刷新、空态文案、快速滚动条与列表模式共用（同见 03 注记）。

书架 · 文件夹模式

fragment_bookshelf2.xml · item_bookshelf_list_group.xml · BookshelfFragment2.kt
  • 文件夹形态：分组样式=「文件夹」（bookGroupStyle=1）时无 Tabs，改为分组与书籍混排（bookGroups + books）BookshelfFragment2.kt:244-249。
  • 分组卡片：圆角卡片内仅显示分组封面 66×90 + 分组名 16sp（长分组名单行省略，见左稿第三张），作者 / 章节 / 徽标均隐藏 item_bookshelf_list_group.xml:16-76、BooksAdapterList.kt:118-134；「›」层级指引 XML 可达：加一个无 id 的 AppCompatImageView（app:srcCompat=@drawable/ic_arrow_right、tint on_surface_variant）即可，纯装饰不涉 Kotlin，ic_arrow_right.xml 已存在。
  • 层级导航：点击卡片进入分组，标题变为「书架(分组名)」并只显示组内书籍；返回键退回根层 BookshelfFragment2.kt:128-142、184-191、MainActivity.kt:100-104。分组为平铺结构（BookGroup 无父子层级），组内只出现书籍条目、不再嵌套分组卡片。
  • 编辑：长按分组卡片打开 GroupEditDialog（重命名 / 设封面 / 删除）BookshelfFragment2.kt:228；顶栏「⋮」菜单与标签模式完全一致（12 项）。
  • 下拉刷新：根层默认可用，进入分组后跟随该分组 enableRefresh 开关 BookshelfFragment2.kt:83-87、132-141；空书架显示「书架还空着…」fragment_bookshelf2.xml:33-48，空态呈现同 03 注记的 drawableTop 配方。
  • 文件夹模式下书籍条目复用 item_bookshelf_list（与标签模式同构），网格布局同理可叠加 BooksAdapterList.kt:15-24。
