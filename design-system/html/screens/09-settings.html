F排查与修复 · 亮色可读性

排查员三条问题的核对：三条分别位于 activity_audio_play.xml:44/:29（听书播放）与 activity_book_info.xml:30（书籍详情），均为 themeMode="dark" 大图穿透页，不涉及本组任何布局/控件。已在本会话对设置体系 7 个相关布局执行 grep -rn "md_white|@android:color/white|#fff|#FFF|ffffff"（view_preference / view_preference_category / item_pref_value_chip / item_icon_preference / view_icon / dialog_recycler_view / activity_config）：0 命中（exit=1），设置行全部走语义令牌，亮色下不存在同类白字。
