01 · 书籍搜索

SearchActivity.kt · activity_book_search.xml · view_search.xml · item_search.xml / item_fillet_text.xml · menu/book_search.xml
搜索框聚焦时显示「输入帮助」层（书架联想 + 搜索历史），提交关键词后切换为多书源聚合结果列表；搜索中标题栏下沿出现 2dp 进度条，右下角迷你 FAB 可停止/续搜。
  • 顶栏（blend，与页面同色无阴影）：返回 + 搜索胶囊（提示「搜索书名、作者」，提交按钮可用，提交即搜）+ 溢出菜单 ⋮。
  • 溢出菜单（menu/book_search.xml）：精准搜索（可勾选，记忆偏好，影响书名匹配方式）/ 书源管理 / 多分组·书源（打开 SearchScopeDialog 选择分组或书源）/ 日志（AppLog）；菜单展开时动态追加「全部书源」与各分组勾选项。
  • 输入帮助层：搜索框聚焦时覆盖列表 —— 「书架」联想 chips（按关键词匹配的书架书籍，点按进详情）；「搜索历史」chips（点按执行搜索，长按爆炸动画删除单条；右侧「清除」全部，带确认弹窗）。
  • 结果条目：按书名+作者聚合，右上角灰色角标为可用书源数；绿色圆点表示已在书架；分类标签（LabelsBar）；最新章节；简介两行截断；点按进书籍详情。
  • 搜索中：标题栏下 2dp 进度条 + 迷你 FAB 停止；手动停止后若还有更多结果，FAB 变播放键续搜；滚动到底自动续搜。
  • 空结果：限定了分组/书源时弹窗引导 —— 关闭精准搜索或切回「全部书源」。

02 · 搜索内容（全文搜索）

SearchContentActivity.kt · activity_search_content.xml · item_search_list.xml · menu/content_search.xml
对当前书籍已缓存章节做全文搜索：章节名 + 命中上下文（关键词主题色高亮），底部信息条统计结果并可快速回顶/到底；阅读页内的搜索浮层（上个/下个结果 + 结果/主菜单/退出）属于阅读页分组，此处为独立全文搜索页。
  • 顶栏（blend）：返回 + 搜索胶囊（提交即搜，返回本页时自动回填上次关键词）+ 溢出菜单。
  • 溢出菜单（menu/content_search.xml）：「启用替换净化」可勾选 —— 开启后命中文本先应用替换净化规则再显示。
  • 结果条目：章节名（主题色）+ 换行 + 命中上下文（关键词主题色）；当前正在阅读的章节整行加粗；章节间弱分割线；FastScroll 快滚条（右缘）。
  • 底部信息条：「搜索结果: N」点按可唤起输入法改词；↑ 回顶部；↓ 到底。
  • 搜索中：标题下 2dp 进度条 + 迷你 FAB 停止；仅搜索本地/已缓存章节。
  • 点按结果：返回阅读页并定位到命中页；无结果显示「搜索内容为空，请检查净化或简繁设置」。

03 · 发现页

ExploreFragment.kt · fragment_explore.xml · item_find_book.xml · item_fillet_text.xml · menu/main_explore.xml / explore_item.xml
每个启用「发现」的书源一行，点按展开其分类 chips（同时仅一个展开），点分类进入发现详情；顶栏搜索框实时筛选发现源，分组菜单按分组过滤。
  • 顶栏（blend）：「发现」标题 + 搜索胶囊（提示「筛选发现」，输入实时过滤源名，支持 group:xxx 语法）+ 分组菜单（ic_groups，子菜单列出各发现分组，点选即过滤）。
  • 源条目：点按标题行展开/收起分类（同时仅一个展开），展开时标题行右侧出现旋转加载（有缓存时近乎秒开）；分类 chips 来自书源探索规则，点按进入发现详情；规则返回 ERROR 的项点按弹出错误文本。
  • 长按源标题弹出菜单：编辑 / 置顶 / 登录（源有登录地址时显示）/ 搜索（进入书籍搜索并限定该源）/ 刷新（清空分类缓存重新加载）/ 删除（确认弹窗）。
  • 空态：没有任何发现源时居中显示「当前没有发现源！」；筛选中不显示空态提示。

04 · 发现详情

ExploreShowActivity.kt · activity_explore_show.xml · item_search.xml · ViewLoadMoreBinding（LoadMoreView）
发现分类下的书籍列表，条目复用书籍搜索结果样式（封面 / 书架绿点 / 书名 / 书源数角标 / 作者 / 分类 / 最新章节 / 简介），滚动到底自动翻页，底部带加载更多 footer。
  • 顶栏（blend）：返回 + 分类名（intent「exploreName」，如「玄幻」；列表来自单一书源的该分类）；本页无溢出菜单。
  • 结果条目：与书籍搜索共用 item_search —— 封面（CoverImageView，过渡动画共享元素）/ 书架绿点 / 书名 / 书源数角标（BadgeView）/ 作者 / 分类标签 / 最新章节 / 简介；点按进书籍详情；条目间弱分割线。
  • 加载更多（LoadMoreView footer）：滚动到底自动翻页，footer 显示旋转加载；没有更多时显示「我是有底线的」；列表为空显示「空」；加载失败显示「加载失败 · 点击查看详情」，点按重试。
