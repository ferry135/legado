02 · 书籍详情流程

覆盖书籍信息的查看与编辑、目录与书签、章节级与整书换源、封面换源六个屏幕。所有功能块、菜单项与操作均取自现存布局与代码（见各屏幕下的来源注记），未虚构、未遗漏；溢出菜单与长按菜单以「功能覆盖」清单逐项落位。

①书籍信息 ②书籍信息编辑 ③目录 · 书签 ④章节换源 ⑤书籍换源 ⑥换封面

06

换封面

dialog_change_cover.xml · ChangeCoverDialog.kt · item_cover.xml · menu/change_cover.xml
功能 3 列封面候选网格（书源名居中展示）点击候选即换封面搜索中进度条无结果空态（停止 ⇄ 刷新已复位为刷新） 顶栏停止 ⇄ 刷新（menu_start_stop）

ChangeCoverDialog 为全屏对话框（无返回键位，返回手势关闭）；顶栏标题固定「封面换源」，菜单仅有开始/停止搜索一项，网格为 GridLayoutManager 3 列。网格候选项的数量随搜索结果增长，示例仅展示部分。无结果空态同 tv_empty_msg 模式（dialog_change_cover.xml 加 gone 的居中空态块），搜索结束后顶栏复位为刷新；空态图标复用②「选择本地图片」的图片描边图标，保持同类图标一致。

流程关系：书籍信息① →「编辑」→ 书籍信息编辑②（保存回写）；① →「查看目录」→ 目录·书签③；①/② →「换源 / 封面换源」→ 章节换源④ / 书籍换源⑤ / 换封面⑥。换源对话框共用 item_change_source 与 menu/change_source，仅标题结构不同。
