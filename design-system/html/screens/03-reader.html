design-system: legado v2 · 屏幕组 03

阅读器

阅读正文与全部阅读内菜单/面板，共 8 屏、明暗并排。主色 #FF6B2C、暖纸白/暖黑表面、8% 弱分割线、大圆角（面板 20dp / 弹层 16dp）、无阴影；全部功能块取自现有布局与代码，无虚构功能。

01

阅读正文

ReadView 全屏正文；页眉/页脚为 ReadTipConfig 可配置提示位；长按选择文本呼出选择菜单。

  • 正文与页眉页脚 — activity_book_read.xml read_view；页眉=标题/时间、页脚=页数及进度/时间及电量（ReadTipConfig.kt:23 真实提示项，PageView.kt:254 分三栏渲染）；正文颜色为用户预设（ReadBookConfig.Config 默认 #3E3D3B，夜间 #ADADAD）。
  • 选择菜单 — 长按选择文本后出现左右游标（cursor_left/right）与悬浮菜单：替换 / 复制 / 书签 / 朗读 / 词典，溢出项：全文搜索 / 浏览器 / 分享（content_select_action.xml）。
  • 点击呼出菜单 — 点击屏幕中部显示/隐藏阅读菜单（ReadBookActivity 点击区域可配置）。
02

阅读菜单（顶部+底部）

view_read_menu.xml 完整菜单：顶栏+章节信息、四个悬浮按钮、章节进度行、四个主按钮。

  • 顶栏 — 返回 + 书名居中 + 换源/刷新/离线缓存/更多（menu/book_read.xml，前三项 showAsAction=always）；下方 title_bar_addition 显示章节名与章节 URL（本地书隐藏 URL），右侧「书源」胶囊点击弹出 登录/购买/编辑书源/禁用书源（book_read_source.xml）。
  • 悬浮按钮行 — 全文搜索 fabSearch / 自动翻页 fabAutoPage / 替换净化 fabReplaceRule / 深色模式 fabNightTheme（夜间模式即时切换明暗主题）。
  • 章节进度行 — 上一章 / seek_read_page / 下一章；进度条行为可设「调整本章页数」或「调整章节位置」（ReadMenu.kt:409-440）。
  • 主按钮行 — 目录 / 朗读（长按打开朗读设置）/ 界面 / 设置。面板圆角 20dp 沿用 bg_read_menu_top/bottom_panel。
03

亮度面板

ll_brightness 垂直亮度面板：自动亮度开关、0–255 亮度条、位置调整。

  • 面板构成 — 自动亮度（开启时主题色高亮、滑条禁用，ReadMenu.kt:268）、垂直亮度条 max=255（view_read_menu.xml:96）、调整位置（左右切换，ReadMenu.kt:562）。
  • 显隐控制 — 由「更多设置 → 显示亮度调节控件」开关控制（showBrightnessView，默认显示）；默认靠左，可切换到右侧。
04

章节跳转

拖动章节进度条跳转；「调整章节位置」行为下松手弹出确认对话框。

  • 进度跳转 — 行为=调整本章页数：直接跳页（skipToPage）；行为=调整章节位置：松手弹出「章节跳转确认」对话框（ReadMenu.kt:422 alert，确认一次后可记住不再询问）。
  • 上一章/下一章 — 章节行两端按钮，首/末章时置灰禁用（ReadMenu.kt:521-522）。
05

界面设置（字体/间距/背景）

ReadStyleDialog 底部弹层：六入口、四组 DetailSeekBar、翻页动画、背景预设。

  • 快捷入口 — 字重（正常/粗体/细体）/ 字体 / 缩进 / 简繁转换 / 边距 / 信息（提示信息配置），对应 dialog_read_book_style.xml 顶部按钮行。
  • DetailSeekBar — 字号（≤45，默认 20）/ 字距（默认 0.1）/ 行距（默认 12）/ 段距（默认 2），行内 −/滑条/+（view_detail_seek_bar.xml）。
  • 翻页动画 — 覆盖 / 滑动 / 仿真 / 滚动 / 无动画 五选一（ThemeRadioNoButton）。
  • 文字颜色和背景 — 长按自定义（BgTextConfigDialog）；「共用布局」复选框横竖屏共享；背景预设圆点 = 微信读书/预设1-5（assets/defaultData/readConfig.json 真实配色）。
06

更多设置

MoreConfigDialog 底部弹层（360dp，可滚动）：阅读行为全部开关与选项。

  • 弹层形态 — 无遮罩底部弹层，高 360dp（MoreConfigDialog.kt:48），列表 = xml/pref_config_read.xml。
  • 完整项清单（28 项） — 屏幕方向、屏幕超时（默认/1/5/10 分钟/常亮）、隐藏状态栏、隐藏导航栏、扩展到刘海、填充刘海区域、平板/横屏双页、进度条行为、使用自定义中文分行、文字两端对齐、文字底部对齐、鼠标滚轮翻页、音量键翻页、朗读时音量键翻页、按键长按翻页、滑动翻页阈值、自动换源、长按选择文本、显示亮度调节控件、禁用滚动点击动画、点击预览图片、启用绘制优化、点击区域设置、禁用返回键、自定义翻页按键、展开文本选择菜单、展示顶部工具栏附加区域、工具栏样式跟随页面。
07

朗读面板

ReadAloudDialog 底部弹层：播放控制、定时、语速、四个导航按钮。

  • 播放控制 — 上一章/下一章 + 上一句/播放暂停/停止/下一句（ReadAloudDialog.kt:104-112）。
  • 定时 — 0–180 分钟滑条；点时间文字弹出预设 选择（0/5/10/15/30/60/90/180 分钟，ReadAloudDialog.kt:135）；点定时图标保存为默认值。
  • 语速 — 朗读语速 0.5–5.0（(progress+5)/10，ReadAloudDialog.kt:210）；「跟随系统」开启时语速滑条禁用。
  • 导航 — 目录 / 主菜单 / 后台播放 / 设置（朗读配置 ReadAloudConfigDialog）。
08

自动翻页

AutoReadDialog 底部弹层：翻页速度调节与停止。

  • 翻页速度 — 1–120 秒，显示 %ds 格式（AutoReadDialog.kt:79）。
  • 底部操作 — 目录 / 主菜单 / 停止 / 设置（设置打开翻页动画配置，AutoReadDialog.kt:103）。
